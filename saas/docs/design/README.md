# Design Knowledge

Organize durable design knowledge by ontology rather than by arbitrary pages.

- `principles.md`: product/design principles
- `tokens/`: primitive, semantic, and component token systems
- `foundations/`: grid, containers, density, breakpoints, accessibility
- `layouts/`: reusable page composition rules
- `components/`: anatomy, variants, states, behavior
- `patterns/`: workflows and recurring UI states
- `content/`: voice, labels, formatting, microcopy
- `anti-patterns.md`: known bad outcomes
- `decisions.md`: accepted design decisions

Observed source material belongs in `REFERENCE.md` or linked evidence; distill it before promoting it to design rules.
