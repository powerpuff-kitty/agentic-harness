# Documentation

## Objective

Keep durable truth concise, current and distinct from evidence, decisions, plans and tasks.

## Inputs

Repository/scope; optional accepted ADR, diff, audience and format.

## Context

Follow target custom routes. Read the changed document and only its supporting ADR/code/evidence. Refresh reused evidence after source or scope changes.

## Procedure

1. Classify content and update its canonical owner; link rather than duplicate rules.
2. Ground claims in accepted decisions and implemented behaviour. Preserve contradictions until resolved; invent no missing choices or delivered features.
3. Deduplicate only equivalent text, retaining qualifiers, exceptions and authority. Keep routers compact and detail conditional.
4. Repair affected links/indexes. Remove stale claims only with evidence; retain ADR history.
5. Run permitted doc/link/schema checks. Report scope, source, exit and distinct failures with actual evidence references. Missing tools or truncated logs do not pass.
6. Reuse existing records instead of creating routine reports/transcript copies. No extra agent or hosted judgment is required.

## Output

Changed docs, sources, contradictions, repaired routes and check outcomes; no unmeasured savings.

## Completion

Changed facts have one canonical owner, history survives, and temporary/inferred content is not promoted silently. Required checks pass or remain explicit unresolved gates.
