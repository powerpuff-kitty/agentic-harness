# Installed skills

Select only the procedure needed for the current task. This index is discovery
metadata, not an instruction to load every skill or its reference guides.
Project-owned truth and approval boundaries remain authoritative.

| Task | Local procedure |
| --- | --- |
| Harness setup, upgrade or broad lifecycle | [agentic-app](agentic-app/SKILL.md) |
| Broad codebase assessment | [codebase-audit](codebase-audit/SKILL.md) |
| Implementation security review | [security-review](security-review/SKILL.md) |
| Durable documentation updates | [documentation](documentation/SKILL.md) |
| Explicitly authorised release work | [release](release/SKILL.md) |
| Instruction or context optimisation | [agentic-improvement](agentic-improvement/SKILL.md) |
| Bounded evidence-backed semantic judgments | [decision-intelligence](decision-intelligence/SKILL.md) |
| Actual TypeSafe integration only | [typesafe-ai](typesafe-ai/SKILL.md) |

The seven Harness procedures and their necessary guides are pinned to the agents
revision in `.agentic/lock.json`. TypeSafe has independent provenance. Lifecycle's
two shared source guides are copied inside its directory; interpret their paths
relative to that skill, and consult only the guide relevant to an unresolved task.
Uninstalled specialists mentioned by a procedure remain optional handoffs, not
proof of local availability or permission to fetch tools or call providers.

Use the documented repository checks to verify delivery. Source presence does not
prove automatic host activation, instruction adherence, live inference or savings.
