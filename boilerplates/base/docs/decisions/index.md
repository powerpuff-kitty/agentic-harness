# Decision Log

Use this directory for durable Architecture Decision Records (ADRs) covering architecture, product, data, security, design, and operational choices.

## Rules

- One decision per file.
- Record context, decision, alternatives, consequences, and status.
- Never silently rewrite history. Supersede old ADRs with a new ADR and link them.
- Prefer decisions that explain *why*, not only *what*.
