# Agentic Packs

Packs are composable domain/technical knowledge modules. They complement the core harness rather than replacing it.

A pack may define required knowledge, suggested docs, skills, evals, examples, and approval gates. Select packs in `agentic.yaml` after repository inspection and user confirmation.

Available starter packs: web-app, design-system, backend-api, saas, mobile, ai-app, data-platform, realtime, security-critical, library-sdk, postgres.
