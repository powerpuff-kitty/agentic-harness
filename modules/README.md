# Modules

Modules are reusable cross-boilerplate building blocks.

- `packs/` — domain and technical knowledge plus constraints.
- `policies/` — mandatory must/must-not rules.
- `profiles/` — organization/team defaults that compose packs, policies, skills, and maturity.

Modules do not define project shape; root boilerplates do. Agent procedures live in `agentic-harness-agents`.
