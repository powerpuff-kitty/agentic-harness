# Reference Evidence

Use this file as an index of observed evidence that informs the project but is not itself a distilled rule: screenshots, Figma frames, brand references, external specs, benchmark products, API documentation, and research sources.

For each durable reference capture what it is, where it came from, when it was checked if time-sensitive, and what conclusions it may support.

Do not promote ambiguous observations directly into `DESIGN.md`, `ARCHITECTURE.md`, or `PRODUCT.md`. Distill and validate first.
