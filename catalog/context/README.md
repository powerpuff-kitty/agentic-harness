# Context selection

`profiles.v1.json` is the canonical file-selection contract consumed by compatible CLI versions, separate from organization profiles under `catalog/profiles/`.

Full remains the compatibility default. Minimal selects the listed core files, conditional design context and selected-module routers from complete materialized variants. Modules and skills still install their complete content. The CLI renders `minimal-map.md` with selected route and module rows; its placeholders must not appear in generated projects.

See [context selection v1](../../.agentic/docs/project/context-selection-v1.md) for preservation, compatibility and evidence semantics. This contract does not imply every published CLI supports it.
