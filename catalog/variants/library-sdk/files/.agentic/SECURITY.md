# Security model

## Protected assets

List data, credentials, identities, capabilities, infrastructure, and business assets that require protection.

## Trust boundaries

Describe users, services, networks, vendors, and privilege boundaries.

## Threats and abuse cases

Identify credible misuse, attacker goals, and failure modes.

## Required controls

Document authentication, authorization, validation, encryption, secret handling, logging, retention, recovery, and review requirements.

## Approval gates

State operations that require explicit human authorization.

## Verification

List security tests, scanners, reviews, and evidence expected for the declared maturity.
