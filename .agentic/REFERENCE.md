# Reference and evidence

This file records concise evidence behind the Agentic Harness architecture. Detailed research belongs under `docs/research/`; accepted choices belong in `decisions/`.

## Evidence categories

- Coding-agent instruction discovery conventions and vendor-required adapter locations.
- Repository customization patterns such as root and scoped `AGENTS.md`.
- Software architecture decision record practices.
- Reproducible build, lockfile, checksum, and release-signing practices.
- Design-system token/component enforcement and accessibility testing.
- Migration safety, idempotence, and backward-compatibility evidence from CLI tests.

For externally sourced claims, record the authoritative source, date checked, supported statement, and uncertainty. Do not copy large external documents into the repository.
