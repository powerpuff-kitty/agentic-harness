# Messaging

## One-liner

Agentic Harness turns software projects into structured, governable environments for coding agents.

## Short description

Agentic Harness is a vendor-neutral framework and native CLI for composing templates, packs, skills, project truth, and deterministic checks into agent-native software projects.

## Long description

Agentic Harness helps developers initialize or upgrade projects for agentic development without relying on one large prompt or one vendor-specific instruction file. It separates product, architecture, design, security, procedures, examples, evals, and policies; composes them through reusable templates, packs, skills, and presets; and provides native validation, audit, security, compare, and gate commands.

## Core messages

1. **Give agents durable project context.** Important knowledge belongs in canonical files, not chat history.
2. **Compose instead of copy-paste.** Reusable templates, packs, skills, and presets can be layered onto new or existing projects.
3. **Stay vendor-neutral.** Thin adapters can point Claude, Codex, Copilot, Gemini, and other agents to shared project truth.
4. **Make important rules deterministic.** Tests, schemas, validation, audits, and CI should enforce what prompts alone cannot.
5. **Preserve existing truth.** Upgrade flows should inspect first and avoid replacing project-specific knowledge blindly.

## Terminology

Preferred:
- agent-native project
- harness
- project truth
- composable
- governed
- deterministic checks
- templates / packs / skills / presets

Avoid unsupported claims such as "fully autonomous", "guaranteed secure", "works with every agent", or performance claims without measured evidence.
