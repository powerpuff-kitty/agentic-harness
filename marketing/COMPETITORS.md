# Competitors and Alternatives

This file tracks categories and alternatives. Concrete competitor claims should be dated and sourced before publication.

## Main alternative categories

### Vendor-specific instruction systems
Examples include repository instruction files, vendor-specific agent configuration, prompt files, and tool-specific rules.

Strength: simple and close to the agent.
Gap Agentic Harness targets: shared canonical truth, cross-agent portability, composability, deterministic validation, and reusable project-level modules.

### Starter repositories and scaffolding tools
Strength: quickly create application structure.
Gap Agentic Harness targets: ongoing governance, upgrades, agent procedures, audits, policies, and knowledge boundaries after initial scaffolding.

### Internal developer platforms / golden paths
Strength: strong organizational standardization.
Gap Agentic Harness targets: lightweight local-first use, vendor-neutral agent context, reusable skills/packs, and adoption without requiring a hosted platform.

### Prompt/skill libraries
Strength: reusable procedures and instructions.
Gap Agentic Harness targets: integration with project truth, templates, policies, evals, audits, and deterministic enforcement.

## Comparison rules

- Date external evidence.
- Compare shipping capabilities, not announced roadmap.
- Separate product category differences from feature checklists.
- Do not claim superiority without a defined criterion and evidence.
