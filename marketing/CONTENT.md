# Content

## Core content pillars

- Agent-native repository architecture.
- Moving from monolithic instruction files to scoped project truth.
- Templates vs packs vs skills vs presets.
- Cross-agent portability and thin vendor adapters.
- Deterministic validation, evals, security, and policy gates.
- Safe upgrades for existing repositories.
- Guided project generation from product intent.

## Useful proof content

- Before/after repository examples.
- Side-by-side use with multiple coding agents.
- Real audit reports and improvements.
- Template/preset walkthroughs.
- Security and permission-boundary demonstrations.
- Case studies once genuine users exist.

Keep examples reproducible and do not invent adoption metrics or testimonials.
