# Launch

## Launch goal

Demonstrate that Agentic Harness can take a new or existing repository and turn fragmented agent configuration into a structured, vendor-neutral, auditable project harness.

## Minimum launch proof

- Precompiled `ah` binaries for major desktop/server platforms.
- Guided initialization and safe upgrade flow.
- Multiple templates and presets.
- Reusable packs and skills.
- Clear example showing one project usable across multiple coding agents.
- Audit/security/validation commands running in CI.
- Documentation explaining the composition model and boundaries.

## Demo narrative

1. Start with an ordinary repository or a short description of an app.
2. Let the agent inspect/ask only important unresolved questions.
3. Resolve template, packs, skills, maturity, and permissions.
4. Generate the harness and project structure.
5. Show multiple agents reading the same canonical truth.
6. Run `ah audit`, `ah validate`, and gates.
7. Upgrade the project without overwriting project-specific truth.

## Candidate channels

GitHub, Hacker News, developer communities, technical blog posts, short demos, agent-tool communities, and launch platforms may be useful. Validate channel fit before investing heavily in any one channel.
